<h2>Get going with one command</h2>
<p>Install the <code>git-meta</code> CLI tool directly on macOS or Linux with our one-line installer:</p>
<pre><code class="language-bash">curl -fsSL https://metastac.kr/install.sh | bash
</code></pre>
<p>Then, run <code>git meta init</code> in your repository to onboard your workspace with automated Git hooks and backend synchronization.</p>
