<h2>Get going with one command</h2>
<p>Compile and install the <code>git-meta</code> CLI tool into your system path using the project Makefile:</p>
<pre><code class="language-bash">make install
</code></pre>
<p>This compiles the CLI binary and copies it to your local path. Then, run <code>git meta install-hooks</code> to align git branch hooks across submodules.</p>
