One command. MetaStackR for You and Your Agent

An event-driven orchestration system and custom CLI (git-meta) that manages multiple submodules transparently. Track local submodule drift, perform bottom-up pushes to prevent dangling pointers, and merge atomically using parallel depth-batch cascade merges topologically. Built with database optimistic locking and GitHub Checks integration to keep development completely aligned.

git meta status View on GitHub

git meta status queries both local submodule drift and live remote statuses, then executes bottom-up pushes, and triggers a Saga cascade merge topologically on the backend daemon.

Check out the MetaStackr repository to get started.

Get going with one command

Compile and install the git-meta CLI tool into your system path using the project Makefile:

make install

This compiles the CLI binary and copies it to your local path. Then, run git meta install-hooks to align git branch hooks across submodules.

Optimistic SQL Locking

Reconciliation loops enforce strict lock_version verification to eliminate race conditions on meta PR updates.

Bottom-Up Pushes

CLI guarantees submodule changes are pushed to remote origins before updating parent pointer commits.

DAG Cycle Detection

Builds a Directed Acyclic Graph of dependencies, aborting immediately with ErrCycleDetected if a loop occurs.

Saga Cascade Merge

Executes merges topologically in parallel depth batches, halting on conflicts without force-reverting base branches.

Single Checks Matrix

Maintains a single GitHub Check Run named meta-repo/sync with a clean markdown matrix table showing approvals and CI.

Git Hooks Drift Check

Installs post-checkout and pre-commit hooks in .git/hooks to verify submodule alignment and detached HEAD states.

Privacy-by-Default

Operates strictly on Git metadata (branches/SHAs) without pulling source code. Toggle allowCodePull: true to opt-in for dry-run merges and static analysis.

Built for you and your AI coding agent

AI compliance guidelines are built directly into the repository rules:

  • AGENTS.md specifies workspace rules, database repository scopes, and optimistic locking requirements.
  • The backend Check Run reports topological errors and cycles dynamically back to coding agent tools.
  • The normalized webhooks pipeline converts provider payloads into a clean domain event structure.

Your agent can now coordinate changes across submodules, query statuses, execute pushes, and run retry merges without breaking references.

Simple Submodule Dependency Declarations

name: MetaStackrConfig
submodules:
  - path: sub/auth-service
    repo: org/auth-service
  - path: sub/ui-app
    repo: org/ui-app
    dependsOn: ["sub/auth-service"]
